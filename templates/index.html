🚀 View Live Dashboard

🔄 How The IoT System Works

1

Ultrasonic Sensing

HC-SR04 / Ultrasonic sensor mounted on bin lid measures distance to waste surface.

2

ESP32 Microcontroller

Processes raw sensor measurements into percentage fill levels and sends HTTP POST payload.

3

Flask Server & DB

Ingests telemetry stream, updates database records, and evaluates threshold alert status.

4

Real-Time Dashboard

Visualizes fill levels, alerts operators when bins exceed 80%, and manages collection workflow.

✨ Core Capabilities

📊

Real-Time Fill Monitoring

Live percentage bars and status badges (Normal ≤50%, Warning 51-80%, Full >80%) updated continuously.

🚨

Instant Capacity Alerts

Automatic high-priority alert cards when bins overflow or reach full capacity, eliminating manual checks.

🚮

One-Click Collection

Sanitation workers can mark bins as collected with one click, resetting levels and database records.

🔌

RESTful Telemetry API

Fully compliant REST API endpoints (`/api/update-dustbin`, `/api/dustbins`) for easy microcontroller integration.
